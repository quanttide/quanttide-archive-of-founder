如果你在 GitHub 想找“小红书长图制作工具”，优先看这几个方向：
AI 图文生成器（会自动拆成多页 3:4 竖图）
文章/Markdown 转小红书风格图片卡片的工具
专门做封面/长图排版的 Skill / 插件
顺带教你如何在 GitHub 更精确地搜这类项目
下面按“能直接用”的优先级给你整理。
一、最推荐：几款能直接出小红书多页长图的开源项目
1. RedInk（红墨）——一句话生成完整小红书图文
仓库：HisMax/RedInk
关键词：小红书 图文 生成、Nano Banana Pro、一句话生成图文
特点：
输入一句话 / 主题，自动生成：封面 + 多页内容（默认 15 页，可配置）
支持上传你的小红书主页截图作为风格参考，保证风格统一
后端 Python + Flask，前端 Vue 3 + TypeScript，Docker 一键部署
适合：博主 / 运营，想要“从主题到成图”一气呵成
典型用法（Docker）：
docker run -d -p 12398:12398 \
  -v ./history:/app/history \
  -v ./output:/app/output \
  histonemax/redink:latest
然后打开 http://localhost:12398，在设置里填入你的文案/图片 API Key 就能用。
如果你只是想“快速出一整套小红书长图文”，这是目前 GitHub 上最成熟、最火的项目之一。
2. xhs-image-mcp —— 文章转小红书风格图片卡片（MCP Server）
仓库：dthinkr/xhs-image-mcp
关键词：MCP、小红书 图片 卡片、文章转图、AI 封面
特点：
把文章 / 文本自动转成小红书风格的 3:4 竖版图片卡片（多页）
智能分页：用浏览器实际测量分页，解决内容溢出问题
4 种主题：minimal / elegant / warm / dark
3 种比例：3:4（推荐）、1:1、4:3
支持 AI 封面：设置 GEMINI_API_KEY 后可自动根据文章生成艺术封面
基于 MCP 协议，可直接集成到 Claude Desktop / Claude Code 等工具
典型用法（npx）：
npm install -g xhs-image-mcp
npx playwright install chromium
在 Claude Desktop 的配置里加：
{
  ”mcpServers“: {
    ”xhs-image“: {
      ”command“: ”npx“,
      ”args“: [”-y“, ”xhs-image-mcp“],
      ”env“: {
        ”GEMINI_API_KEY“: ”your_api_key_here“
      }
    }
  }
}
适合：已经有长文 / Markdown，想快速拆成一套小红书风格长图卡片的人。
3. Xiaohongshu-Content-Generator —— 带 HTML 转图片的图文生成器
仓库：shaozheng0503/Xiaohongshu-Content-Generator
特点（从代码和依赖推断）：
使用 html2image 把 HTML 转成图片
有一个简单的 Web 界面，输入内容后生成小红书图文
偏轻量、适合自己二次开发
如果你只是想看看“HTML 怎么转小红书长图”，这个项目结构简单，适合改着玩。
4. xiaohongshu-skills（封面生成 Skill）
仓库：freestylefly/xiaohongshu-skills
关键词：xiaohongshu-cover-generator、小红书 封面 图 生成
特点：
专门生成小红书风格封面图的 Skill（插件）
用 TypeScript 写，依赖 node-fetch，调用 Canghe AI 的 API
更偏“给 AI 助手用的技能插件”，适合接入你自己的工作流
如果你已经在用某种 Skill 框架（比如 Claude Code / 其他 Skill 生态），可以把它当成一个“封面生成模块”。
5. YYH211/xiaohongshu —— 小红书内容生成 + 自动发布系统
仓库：YYH211/xiaohongshu
特点：
从主题 → 内容 → 排版 → 发布到小红书的完整系统
集成 MCP 服务（Jina / Tavily 搜索 + 小红书发布 MCP）
重点是“自动发布”，排版/图片是其中一环
如果你想要的是“从选题到发布一条龙”，可以看这个；但长图制作能力相对前面几项没那么专精。
二、偏“Skill / 插件”的小红书图文生成器
这些不是传统 Web 应用，而是给 AI 助手（Claude Code、Cursor、Codex 等）用的“技能”，通过命令一键生成多页小红书图文。
1. openclaw-skills / xiaohongshu-post-gen
位置：openclaw/skills 里的 xiaohongshu-post-gen
特点：
自动把文本拆成：封面 + 最多 9 页内容（共 10 页）
3:4 竖版优化，适配小红书
多种布局：封面、正文、引用、清单、结尾页等
4 种主题：dreamy / tech / minimal / warm
命令行一键生成，比如：uv run skills/xiaohongshu-post-gen/scripts/gen_post.py \
  —title ”你的标题“ \
  —content ”你的正文内容“ \
  —output ./my-post/
适合：已经在用 uv + Skill 生态，想一行命令出整套小红书图文的人。
2. baoyu-skills 中的 baoyu-xhs-images
仓库：JimLiu/baoyu-skills
特点：
里面有多个 Skill，其中 baoyu-xhs-images 专门把文章拆成 1–10 张小红书风格卡片图
支持信息图、PPT、封面等多种技能，可组合使用
如果你想要一整套“内容 + 多平台配图”工作流，可以一起看这个仓库里的其它 Skill。
三、如何在 GitHub 自己搜“小红书长图制作工具”
如果你还想自己多翻几个项目，可以直接用 GitHub 搜索 + Topics 过滤。
1. 用中文关键词搜
在 GitHub 搜索框里试试：
小红书 图文 生成
小红书 长图
小红书 封面 生成
小红书 图片 卡片
示例：
小红书 图文 生成 in:readme,description
小红书 长图 in:readme,description
加上 in:readme,description 可以限制只在 README 和仓库描述里搜，减少噪音。
2. 用英文关键词搜
一些项目只用英文名：
xiaohongshu image generator
xiaohongshu post generator
xiaohongshu cover
xhs image mcp
示例：
xiaohongshu image in:readme,description
xhs cover in:readme,description
3. 利用 Topics 过滤
GitHub 有 xiaohongshu 这个 Topic：
进入 GitHub 搜索页
搜索框输入：xiaohongshu
在左侧边栏勾选 Topics，只看带 xiaohongshu 标签的仓库
这样能快速过滤出专门为小红书做的项目。
四、怎么选适合你的那一个？
简单按需求分一下：
你想干嘛	推荐优先级	典型项目	
一句话出整套小红书图文（封面 + 多页长图）	最高	HisMax/RedInk	
已有长文/Markdown，想拆成小红书多页卡片	高	dthinkr/xhs-image-mcp	
想把生成逻辑接入 AI 助手（Skill / MCP）	中	xiaohongshu-post-gen、xiaohongshu-skills	
想要从选题 → 内容 → 排版 → 发布一条龙	中	YYH211/xiaohongshu	
只想做个封面 / 想自己改代码玩	低~中	Xiaohongshu-Content-Generator、xiaohongshu-skills	
如果你能简单说一下：
更偏“本地部署”还是“在线用”，
想要“AI 自动生成内容”还是“只负责排版/出图”，
我可以帮你从上面这些里挑一个，给一个更具体的安装 + 使用步骤。
