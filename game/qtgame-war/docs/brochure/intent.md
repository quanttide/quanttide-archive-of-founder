# 指挥意图

## 你是什么立场，决定了你能做什么

大多数策略游戏给你一个选项菜单。所有选项都在那里，灰掉的告诉你"你现在不能做这个"。

《指挥官》不是这样。

你锁定一个意图之后，你的世界里就没有某些选项了。不是它们被禁用了，是它们根本不存在于你的决策空间里。

一个决心保护平民的指挥官，看不到"无差别火力覆盖"这个按钮。

## 意图从哪来

不是你自己选的。是你面临的局势告诉你的。

- 包围了帝丘店、敌援军在路上 → 你的意图是"积极防御"，抢时间吃掉当面之敌
- 进攻开封，40 万居民没疏散 → 你的意图是"保护平民"，省会城市的政治代价太高
- 敌情不明，番号都没搞清楚 → 你的意图是"收集情报"，先摸清状况再动手

每个战役开局就给了你一个意图。它是局势强加给你的。

## 可以改，每次改都有代价

战场上的判断会变。粟裕在豫东战役里改了四次——原定打五军，发现打不了，转攻开封；攻下开封，发现敌军出现缝隙，转围区寿年；围到一半，黄百韬逼近，转而迎击。

你也可以改。但每次改意图，消耗 +1。

这个消耗不是惩罚——它是时间。改变决心需要重新部署部队、调整后勤、通知各部队。你在改意图的时候，战场在继续走。

## 情报在意图下折射

同一份情报，在不同意图下看起来不一样。

> 敌军约2000人在西北方向移动。意图不明。

- **保护平民** → 当地村庄面临威胁。
- **积极防御** → 侦察兵注意到我方在构筑攻势阵地。他们可能预判您将出击。
- **收集情报** → 情报显示敌军有异动。建议派出侦察分队确认其真实意图。

事实是一样的，但立场决定了你看到什么。

## 游戏中体现

每局开始，你看到的不是空白的面板。你看到的是：当前局势、当前意图、当前情报。你可以维持它继续推进，也可以重新判断、切换意图。兵棋引擎在底层跑真实的战场——移动、攻击、伤亡——但你的决策界面，是意图驱动的。

这就是为什么它不是一个兵棋推演器。它是指挥官决策游戏。
