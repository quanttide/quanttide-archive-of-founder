## Phase B — 概念确认（当前阶段）

确定"玩家和兵棋引擎之间要不要设参谋长这一层"，以及 Flutter 实现方案。

### B1 核心定论

以下问题已在 Phase B 实验中得出定论，B3 评审前确认即可：

1. **参谋长是连接指挥官和兵棋引擎的中间层。** 玩家不直接操作兵棋引擎——他通过参谋长来指挥部队。这个"隔一层"的摩擦正是沉浸感的来源。
2. **意图不是给玩家看的，是给参谋长看的。** 玩家通过决策表达意图，参谋长理解意图后调配兵棋系统资源。意图反馈不是系统对玩家的注释，是参谋长对指挥官判断的确认。
3. **参谋长 = LLM，有限智商天然成立。** 不需要额外设计错误机制。LLM 的局限性（遗漏情报、被误导、误解意图）本身就是沉浸感来源。
4. **纠错流程比准确率重要。** 当参谋长理解错了，对话界面是否允许指挥官纠正——不是让参谋长理解得更准。
5. **情报本身应当充分。** 参谋长分析是附加值层，不是必经层。玩家只看情报也应能做决策。

### B2 设计评审（B3 更新）

> 旧称 B3。原"选项 A vs 选项 B"的二选一已被新认知取代。评审问题已变化。

- [ ] **核心决策：玩家和兵棋引擎之间，要不要设参谋长这一层？**
  - **设（参谋长模式）**：玩家通过 LLM 参谋长指挥部队，参谋长分析情报、理解意图、操作兵棋系统。意图是参谋长的理解产物，不是玩家的操作入口。玩家不直接接触兵棋引擎。
  - **不设（兵棋模式）**：玩家直接操作兵棋引擎，当前帝丘店战役的交互保持不变。意图不作为一个独立系统存在——需要的场合以决策选项的附加属性体现。
  - 两者不冲突。同一款游戏中两种模式可选，取决于玩家想在哪层粒度上指挥。
- [ ] 确定后，明确 Phase C 的实现范围

## Phase C — 参谋长模式 Flutter 实现（假设通过评审）

> 以下为"设参谋长这一层"的实现任务。如果评审不设，路线图回退到 Phase A 原型后的直接兵棋引擎对接。

### C1 参谋长 LLM 模型

- [ ] 定义参谋长提示词结构：
  - 角色设定：参谋长，分析情报、给出建议，不做决策
  - 输入：当前情报文本 + 时效 + 可信度
  - 输出：局势判断 + 意图建议 + 理由
- [ ] 定义参谋长理解意图的接口：
  - 输入：玩家最近一次决策文本 + 当前情报上下文
  - 输出：参谋部理解的当前意图 + 判断依据
  - 意图 enum 不作为硬编码约束——参谋长理解输出不应限制
- [ ] 定义参谋长操作兵棋系统的接口：
  - 输入：当前意图理解 + 玩家最新决策
  - 输出：兵棋操作序列（下一回合的资源分配、部队调动指令）
- [ ] 试验：检查不同 LLM 在相同情报和决策下的输出一致性（不需要高一致，熟悉偏差范围即可）

### C2 交互流程

- [ ] 情报面板：纯文本灰底，显示情报原文 + 时效 + 可信度标记。玩家先看到情报，不是意图按钮
- [ ] 参谋长分析框：虚线边框不同底色。位置在情报下方，固定显示（不是弹窗/隐藏栏）。标记"参谋部 · 仅供指挥官参考"
- [ ] 玩家决策入口：行动按钮（实心按钮）。按钮描述是具象的战斗指令（"在106高地方向构筑防坦克阵地"），不是抽象意图（"选择积极防御"）
- [ ] 参谋长理解反馈：玩家决策后，参谋长输出"参谋部理解您的意图是...，正在调整部署"。当理解正确时直接执行；当理解错误时——
- [ ] 纠错流程：玩家看到参谋长的理解反馈后，可以纠正（"不是，我是要打援"）。参谋长收到纠正后修正理解，重新输出操作序列
- [ ] 步骤指示器：情报接收 → 参谋长分析 → 指挥官决策 → 参谋长理解 → 兵棋执行

### C3 意图推断与切换

- [ ] 参谋长从玩家决策文本中推断意图（LLM 输出，不是规则映射）
- [ ] 当参谋长识别到意图与上一轮不同时，显示切换成本：
  - 时间推进 +1 回合
  - 部队重新部署（前一个命令中断）
  - 正在传递中的情报可能失效
- [ ] 短期多次切换：成本递增
- [ ] 玩家不需"确认切换"——参谋长理解并执行就是切换本身

### C4 可选：跳过参谋长

- [ ] 玩家可选择"直接指挥"模式，跳过参谋长分析，行动按钮直接映射兵棋引擎指令
- [ ] 此时意图系统不介入——玩家直接操作兵棋引擎
- [ ] "直接指挥"和"参谋长模式"可在战役中随时切换

### C5 验证

- [ ] 纠错流程完整：参谋长理解错 → 玩家纠正 → 参谋长修正理解 → 兵棋系统按修正后指令执行
- [ ] 参谋长不会被同一个错误理解反复带偏（不会陷入"我理解错了"→"玩家纠正"→"又理解成同一个错"的死循环）
- [ ] 玩家不看参谋长分析也能做出决策（情报面板和行动按钮之间链路的完备性）
- [ ] 误导场景中参谋长给出"合理但不正确"的建议（验证 LLM 输出在恰当场景下有迷惑性）
- [ ] 不同 LLM 在相同输入下的输出差异不影响游戏流程（LLM 差异在可接受范围内）
