# 指挥部页面

整体布局为「顶栏 + 三栏主区 + 底栏」结构。

## 页面分区

| 区域 | 内容 | 定位 |
|------|------|------|
| 顶栏 | 怀表倒计时、阶段指示器、部队信号灯、日期 | 全局状态概览 |
| 左栏 | 情报看板 | 情报研判决策 |
| 中栏 | 战场地图 | 战场态势可视化 |
| 右栏 | 作战计划 | 兵力对比、预案选择、命令签署 |
| 底栏 | 通信科 | 部队联络状态 |

## 布局约束

- 最小宽度 1100px，最大 1600px
- 左栏固定宽 220，中栏自适应（最小 500），右栏固定宽 260
- 水平超出时横向滚动
- 深色木质背景，卡片为仿羊皮纸色

## 页面流程

用户操作路径：研判情报（左）→ 查看战场（中）→ 对比兵力（右）→ 选择预案（右）→ 签署命令（右）→ 全局锁定

签署命令后全页面进入「执行中」状态：
- 所有情报卡片不可勾选
- 所有预案不可切换
- 命令稿只读
- 地图锁定
